# hostfully

Hostfully — short-term rental property management platform with a developer-grade REST API (v3.3), GraphQL endpoint, and webhooks.

- Website: https://www.hostfully.com
- Developer portal: https://dev.hostfully.com
- API reference: https://dev.hostfully.com/reference/getting-started
- GraphQL API: https://dev.hostfully.com/reference/hostfully-graphql-api
- Webhooks: https://dev.hostfully.com/reference/webhooks-1
- llms.txt: https://dev.hostfully.com/llms.txt

## APIs

- **Hostfully REST API** — v3.x property management surface (Properties, Leads, Bookings, Group Bookings, Orders, Fees, Owner Adjustments, Messaging, Webhooks, Photos, Amenities, Jobs, Custom Data, Agencies, Employees, Owners, Guests, Reviews). OAuth 2.0 / Basic Auth / `X-HOSTFULLY-APIKEY`. 10,000 calls/hour per client.
- **Hostfully GraphQL API** — GraphQL endpoint for shaped queries and mutations across the same domain.
