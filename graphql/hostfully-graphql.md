# Hostfully GraphQL API

Hostfully GraphQL endpoint for executing queries and mutations against the same underlying property-management domain as the REST API. Useful for clients that need to shape responses, fetch multi-resource graphs in a single round trip, or build internal dashboards on top of Hostfully data.

**Documentation:** https://dev.hostfully.com/reference/hostfully-graphql-api
